# Papers y referencias

Material de soporte para *Antecedentes* (Art. 6b.3), *Marco teórico* (Art. 6b.5) y *Bibliografía tentativa* (Art. 6b.9).

- Guardar aquí fichas de lectura (`autor_año_tema.md`) y, cuando la licencia lo permita, el PDF del trabajo. Para papers de arXiv basta con el enlace en la ficha.
- Las referencias se citan en estilo a definir (propuesta: APA 7.ª ed.) y en la bibliografía final van en orden alfabético, incluyendo únicamente las obras mencionadas en el texto (Art. 9c del reglamento).
